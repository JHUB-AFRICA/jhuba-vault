# Required supplied logo assets

Place the three original supplied PNG files in this directory with these exact names:

- `jkuat.png` - Jomo Kenyatta University of Agriculture and Technology emblem
- `jhub.png` - JHUB Innovations for Transformation logo
- `jhub-africa.png` - JHUB Africa Innovations for Transformation logo

The Angular `BrandLogoComponent` references these files and preserves their proportions. Do not redraw, recolor, compress, or replace them with generated artwork.
